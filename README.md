# Poojitha Ramkumar — Portfolio

A personal portfolio website for **Poojitha Ramkumar**(me), a Computer Science and Engineering student at Chennai Institute of Technology (2025–2029).

Built with a warm editorial aesthetic using pure vanilla web technologies — no frameworks, no bundlers, and zero dependencies.

---

## ✦ Overview & Highlights

- **Retro PC Boot Screen**: Interactive inline SVG desktop computer with tactile keyboard interaction, CRT scanlines, diagnostic boot sequence, and camera zoom transition.
- **Hero & Typography**: Kinetic name decryption with cursor proximity elevation, paired with a velocity-responsive ticker marquee.
- **Project Cards**: Sticky stacking project showcases including a live in-browser WebCrypto SHA-256 demo and Pomodoro focus timer.
- **Explorations Roadmap**: Interactive straight timeline highlighting backend explorations and learning projects (Web Scraping, FastAPI Blog API).
- **Experience & Education**: Dynamic self-drawing timeline featuring internships (Infologia Technologies, InAmigos Foundation, LambdaDigital), FOSS Club at CIT, and academic background.
- **Design & Performance**: Custom warm palette (ivory, sand, espresso, terracotta), Fraunces & Manrope typography, accessible keyboard navigation, and responsive across all screen sizes.

---

## 🛠 Tech Stack

- **Markup**: HTML5 (Semantic, Accessible)
- **Styling**: Modern CSS3 (Custom properties, CSS Grid, Flexbox, Sticky positioning)
- **Scripting**: Vanilla JavaScript (ES6+, Web Crypto API, Intersection Observer)
- **Build Tools**: None (Runs directly in any modern browser)

## 🚀 Quick Start

Run a lightweight local server:

```bash
# Python 3
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser. Alternatively, open `index.html` directly.
